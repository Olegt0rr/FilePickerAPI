# Требования проекта

## Директория с файлами зашивается в сборку

Пользователь на месте не должен иметь возможности подменить директорию,
из которой приложение отдаёт файлы платёжных поручений.

- Путь для каждого филиала задаётся только в `branches.toml` и зашивается
  в `FilePickerAPI.exe` при сборке в CI (`scripts/branches.py configure`).
- Не добавлять способов переопределить путь при запуске: переменные
  окружения, `.env`, аргументы командной строки, конфиги рядом с exe,
  параметры в bat-файлах и т.п. Поэтому `Settings.files_directory` -
  `ClassVar`, а не поле настроек.
- Предложения «собрать один exe и класть путь в конфиг/`.env` рядом»
  отклоняются, даже если это ускоряет сборку.
- Требование закреплено тестами `TestFilesDirectoryNotOverridable`
  в `tests/test_branches.py`; не ослаблять и не удалять их.
