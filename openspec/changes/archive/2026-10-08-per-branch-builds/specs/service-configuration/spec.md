## MODIFIED Requirements

### Requirement: Директория с файлами зашивается в сборку
Сервис SHALL обслуживать файлы из одной директории, путь к которой зашивается в исполняемый файл при сборке. Для каждого филиала из `branches.toml` SHALL собираться отдельная сборка со своим путём. Без записанного пути филиала сервис SHALL обслуживать `./files`; если путь записан, но не загружается, сервис MUST NOT переключаться на `./files`.

#### Scenario: Запуск без настройки
- **WHEN** сборка филиала 5400 запущена без каких-либо параметров
- **THEN** `GET /files` и `GET /files/{fileId}` работают с директорией `\\localmq.neadru.local\Payments\5400\CENTER\RSB`

#### Scenario: Запуск из исходного кода
- **WHEN** сервис запущен через `python -m app`, а путь филиала не записан (`scripts/branches.py configure` не выполнялся)
- **THEN** сервис обслуживает директорию `./files`

#### Scenario: Сломанный конфиг сборки
- **WHEN** путь филиала записан, но его загрузка завершается ошибкой
- **THEN** сервис не запускается и не обслуживает `./files`
