## MODIFIED Requirements

### Requirement: Сборка для Windows
Проект SHALL собираться через Nuitka в режиме standalone: папка `FilePickerAPI` с `FilePickerAPI.exe`, его зависимостями и bat-скриптами, которая запускается без установленного Python. Под каждый филиал из `branches.toml` SHALL собираться своя папка. Режим onefile MUST NOT использоваться: он распаковывает неподписанные файлы во временную папку пользователя, что несовместимо с подписью и WDAC/AppLocker. Сборка SHALL выполняться в CI параллельно с линтером и тестами, а артефакт `FilePickerAPI-<филиал>` SHALL публиковаться только после успешного прохождения линтера, тестов и сборок всех филиалов. Каждая сборка хранится один день как временный артефакт `untested-FilePickerAPI-<филиал>`: по нему CI выполняет пробную подпись, но релиз MUST NOT использовать его.

#### Scenario: Сборка в CI
- **WHEN** в ветку `main`/`master` отправлен коммит или открыт pull request в одну из этих веток
- **THEN** CI запускает ruff и pytest на Linux и pytest на Windows и одновременно собирает папку `FilePickerAPI` на Windows для каждого филиала из `branches.toml`. Когда линтер, тесты и все сборки прошли, CI публикует каждую сборку как артефакт `FilePickerAPI-<филиал>` (например, `FilePickerAPI-5400`)

#### Scenario: Тесты упали
- **WHEN** линтер или тесты завершились с ошибкой
- **THEN** артефакты `FilePickerAPI-<филиал>` не публикуются и пробная подпись не выполняется, а временные артефакты сборок истекают через день

#### Scenario: Сборка филиала упала
- **WHEN** линтер и тесты прошли, а сборка одного из филиалов упала
- **THEN** артефакты `FilePickerAPI-<филиал>` не публикуются ни для одного филиала

#### Scenario: Путь филиала в сборке
- **WHEN** CI собирает папку филиала 5400
- **THEN** перед компиляцией CI сверяет записанный путь с `files_directory` филиала 5400 в `branches.toml` и при расхождении сборка падает; сборки филиалов отличаются только зашитой директорией с файлами

#### Scenario: Ошибка в списке филиалов
- **WHEN** `branches.toml` не проходит проверку (см. «Список филиалов»)
- **THEN** джоб со списком филиалов падает с сообщением о причине, и ни одна сборка не выполняется
