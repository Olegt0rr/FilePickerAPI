# Пробная сборка службы Windows

Черновая проверка для изменения `openspec/changes/windows-service` (задачи 1.1–1.4) до реализации. Приложение не собирается: проверяется только то, на чём держится дизайн.

- `probe_pkg/__main__.py` — минимальная служба на `servicemanager`: событие при запуске и остановке. Без аргументов не под диспетчером служб выводит отчёт в JSON (консольный режим после ошибки 1063), включая признак, выполнила ли сборка Nuitka `__init__.py` пакета раньше точки входа.
- `probe.mc` — файл сообщений: у каждого кода текст `%1`.
- `probe-smoke.ps1` — проверка на Windows-раннере: консольный режим, служба под `NT SERVICE\FilePickerProbe`, текст событий с кириллицей через `Get-WinEvent` и `wevtutil`, остановка без оставшегося процесса.
- `.github/workflows/spike-probe.yml` — сборка и проверка в CI; отчёт Nuitka (`--report`) и результаты — в артефакте `windows-service-probe`.

После проверки результаты переносятся в `design.md` изменения, а эта папка и воркфлоу удаляются.
