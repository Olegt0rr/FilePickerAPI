## ADDED Requirements

### Requirement: Описание релиза
Описание релиза SHALL содержать текст про установку и конфигурацию из `release.yml`, а под ним — автоматический список изменений GitHub с предыдущего релиза. Если релиз для тега уже создан через интерфейс GitHub, воркфлоу SHALL обновлять его, а не создавать второй, и описание SHALL получаться таким же, как при отправке тега из терминала.

#### Scenario: Тег из терминала
- **WHEN** в репозиторий отправлен тег `v2.3.0`
- **THEN** релиз создаётся черновиком, к нему прикладываются архивы филиалов, затем он публикуется, а в описании есть текст про установку и под ним список изменений с предыдущего релиза

#### Scenario: Релиз через интерфейс GitHub
- **WHEN** релиз `v2.3.0` с новым тегом создан и опубликован через интерфейс GitHub
- **THEN** воркфлоу прикладывает архивы филиалов к этому же релизу, второй релиз не появляется, а описание заменяется текстом про установку и списком изменений с предыдущего релиза

#### Scenario: Повторный запуск релиза
- **WHEN** воркфлоу релиза для того же тега запускается повторно
- **THEN** описание релиза не дублируется: в нём один раз текст про установку и один раз список изменений
