# Proposal

## Why

После изменения `user-logon-autostart` сервис ставится MSI-пакетом и запускается при входе пользователя, а `run_test.bat` и `run_production.bat` остаются в архиве сборки только для филиалов, которые ещё не переведены. Когда на MSI переведены все машины, скрипты больше не нужны, а их поддержка сохраняет риски, ради которых делался перевод: логику запуска на cmd не проверить автотестами, и в ней легко ошибиться (подмена системных утилит, `errorlevel`, `pushd` по UNC-пути).

## What Changes

- **BREAKING (3.0.0):** `run_test.bat` и `run_production.bat` удаляются из репозитория и из архива сборки. Запуск сервиса — только при входе пользователя после установки MSI или `FilePickerAPI.exe` без аргументов из консоли.
- Из спецификации `distribution` удаляется требование «Скрипты запуска для Windows»; в папке сборки и в архиве релиза bat-скриптов нет.
- Дымовая проверка в CI дополнительно проверяет, что в папке сборки нет `*.bat`.
- README, текст релиза, Purpose спецификации `distribution`, `openspec/config.yaml` и `CLAUDE.md` больше не упоминают bat-скрипты как способ запуска.

Контракт HTTP API не меняется. Способов задать директорию с файлами при запуске не появляется.

Вне рамок изменения:
- Сам MSI, запуск при входе и поведение сервиса — это `user-logon-autostart`.
- Перевод филиалов на MSI — делается до этого изменения; оно выполняется, только когда переведены все машины.

## Capabilities

### New Capabilities

### Modified Capabilities
- `distribution`: требование «Скрипты запуска для Windows» удаляется. «Сборка для Windows» — в папке сборки нет bat-скриптов. «Автоматический релиз» — архив содержит папку без bat-скриптов.

## Impact

- Удаляются `run_test.bat` и `run_production.bat`; правило `*.bat` в `.gitattributes` удаляется, если других bat-файлов не осталось.
- `.github/workflows/build-exe.yml` — удаляется копирование bat в папку сборки; `.github/scripts/msi-smoke.ps1` — проверка отсутствия `*.bat` и без запуска `run_test.bat`.
- `.github/workflows/release.yml`, `README.md`, `openspec/config.yaml`, `CLAUDE.md`, Purpose в `openspec/specs/distribution/spec.md`.
- Эксплуатация: на машине, где сервис ещё запускается через `run_production.bat`, обновление архива до 3.0.0 сломает запуск. Перед релизом 3.0.0 нужно убедиться, что все машины переведены на MSI.
- Зависимость: выполняется после архивации `user-logon-autostart`. Дельта `distribution` написана поверх требований в том виде, какой они получат после неё.
