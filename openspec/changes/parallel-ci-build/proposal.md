# Proposal

## Why

Build and Test на PR идёт около 10,5 минуты, хотя сами тесты занимают 1–2 минуты. Сборки Nuitka под филиалы (около 5 минут каждая) стартуют только после тестов на Ubuntu и Windows, и тесты целиком лежат на критическом пути. Кроме того, каждая сборка заново собирает wheel Nuitka из исходников (на PyPI есть только sdist), а установка зависимостей на Windows занимает 30–50 секунд.

## What Changes

- Список филиалов для матрицы считает отдельный короткий джоб `matrix` (только `scripts/` и `branches.toml`, без зависимостей проекта), а сборки филиалов ждут только его и идут параллельно с линтером и тестами.
- Сборка выкладывает временный артефакт `untested-FilePickerAPI-<филиал>` на один день. Постоянный артефакт `FilePickerAPI-<филиал>` (30 дней) делает из него джоб `publish`, только когда прошли линтер, тесты и сборки всех филиалов; временный артефакт при этом удаляется. Пробная подпись (`sign-smoke`) и `release.yml` скачивают сборки по шаблону `FilePickerAPI-*`, под который временные артефакты не подходят, поэтому непроверенная сборка до подписи не доходит.
- Кэш pip (`actions/cache`) в тестах, сборке и аудите. Ключ — набор extras и коммит, как у кэша Nuitka: джобы с разными extras не затирают кэш друг друга, а новые версии незакреплённых пакетов попадают в кэш. Релизная сборка по тегу, как и без кэша Nuitka, ставит пакеты без кэша.
- Nuitka обновлена до 4.3.5.
- Требование «Сборка для Windows» описывает новый порядок. Ту же формулировку получают дельты этого требования в незаархивированных изменениях `remove-bat-scripts` и `user-logon-autostart`, чтобы порядок их архивации не возвращал прежний текст.
- README и `openspec/config.yaml` описывают новый порядок.

Контракт HTTP API не меняется: поля, коды ответов и тексты `detail` остаются прежними.

Вне рамок изменения:
- Отмена уже запущенных сборок, если тесты упали: сборки доходят до конца и тратят минуты Windows-раннеров. Отмена прогона из джоба показала бы его как отменённый, а не как упавший.
- Ускорение самой сборки Nuitka (флаги, исключение неиспользуемых модулей) и вынос дымовой проверки MSI в отдельный джоб — отдельными изменениями.
- `pytest-xdist` и другие ускорения тестов: после изменения тесты не на критическом пути.
- Способы задать директорию с файлами при запуске не добавляются; сборка под каждый филиал остаётся.

## Impact

- `.github/workflows/build-exe.yml` — джобы `matrix` и `publish`, `needs` сборки и `sign-smoke`, кэш pip.
- `.github/workflows/audit.yml` — кэш pip.
- `pyproject.toml` — Nuitka 4.3.5.
- `README.md`, `openspec/config.yaml` — описание CI.
- `openspec/changes/remove-bat-scripts`, `openspec/changes/user-logon-autostart` — формулировка CI в дельте «Сборка для Windows».
- `release.yml` не меняется: он подписывает сборки, только когда `build-exe.yml` завершился целиком, и скачивает их по тому же шаблону `FilePickerAPI-*`.
