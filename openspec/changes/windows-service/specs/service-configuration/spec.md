## MODIFIED Requirements

### Requirement: Пользователь не может подменить директорию
Пользователь на месте установки MUST NOT иметь возможности подменить директорию, из которой сервис отдаёт файлы. Сервис MUST NOT принимать путь к директории при запуске ни одним способом:
- переменные окружения (в том числе переменные окружения службы);
- `.env`;
- аргументы командной строки `FilePickerAPI.exe` (в том числе команд `install` и `remove`);
- аргументы в пути к exe службы;
- конфигурационные файлы рядом с exe.

Сменить директорию можно только новой сборкой; схема «один exe плюс путь в конфиге рядом» не допускается.

#### Scenario: Переменная окружения игнорируется
- **WHEN** сервис запущен с переменной окружения `FILES_DIRECTORY=/app/files`
- **THEN** сервис по-прежнему обслуживает зашитую при сборке директорию

#### Scenario: Путь в `.env` не принимается
- **WHEN** в файле `.env` в рабочей директории (для `FilePickerAPI.exe` — в папке exe) указан `FILES_DIRECTORY`
- **THEN** сервис не запускается и не начинает обслуживать указанную в `.env` директорию

#### Scenario: Путь в аргументах не принимается
- **WHEN** `FilePickerAPI.exe` запущен с аргументами, отличными от `install` и `remove` (например, `FilePickerAPI.exe D:\other`, `FilePickerAPI.exe --files-directory D:\other` или `FilePickerAPI.exe install D:\other`)
- **THEN** exe выводит сообщение об использовании, завершается с кодом 2, не запускает сервис и не устанавливает службу

### Requirement: Запуск сервиса
При запуске как приложения (`python -m app`, `FilePickerAPI.exe` в консоли или службой Windows) сервис SHALL пытаться создать обслуживаемую директорию, если она не существует (включая родительские директории). Ошибка создания MUST NOT останавливать запуск: сервис пишет предупреждение с временем и уровнем в журнал своего режима (консоль; для службы — файл журнала и журнал событий Windows) и продолжает работу. `FilePickerAPI.exe` SHALL работать с рабочей директорией, равной папке exe, независимо от того, откуда его запустили. Сервис SHALL принимать HTTP-запросы на всех сетевых интерфейсах (`0.0.0.0`) на порту 8000.

#### Scenario: Директория отсутствует при запуске
- **WHEN** сервис запускается, а обслуживаемой директории нет, но её можно создать
- **THEN** директория создаётся вместе с недостающими родительскими (в том числе на сетевом ресурсе, если у учётной записи сервиса есть права на запись), и сервис начинает принимать запросы на порту 8000

#### Scenario: Сетевая папка недоступна при запуске
- **WHEN** сервис запускается, а сетевая папка недоступна
- **THEN** в журнал пишется предупреждение, сервис принимает запросы, а `GET /files` отвечает ошибкой (см. `file-listing`), пока папка не станет доступна

#### Scenario: Доступ по сети
- **WHEN** сервис запущен на машине с адресом `192.168.1.10`
- **THEN** API доступен по адресу `http://192.168.1.10:8000`

#### Scenario: Рабочая папка exe
- **WHEN** `FilePickerAPI.exe` запускается диспетчером служб (рабочая папка `C:\Windows\System32`) или из консоли в другой папке
- **THEN** сервис читает `.env` из папки, где лежит `FilePickerAPI.exe`, а не из папки, откуда его запустили

### Requirement: Настройка CORS
Сервис SHALL применять политику CORS ко всем эндпоинтам. Список разрешённых источников SHALL задаваться переменной окружения `CORS_ORIGINS` или одноимённым параметром в файле `.env` в рабочей директории (для `FilePickerAPI.exe` — в папке exe) в виде строки через запятую. Пробелы вокруг элементов и пустые элементы отбрасываются. Если переменная не задана или после разбора список пуст, сервис SHALL разрешать все источники (`*`). Разрешены любые методы и заголовки.

#### Scenario: Все источники по умолчанию
- **WHEN** `CORS_ORIGINS` не задана, а клиент отправляет запрос с заголовком `Origin: http://example.com`
- **THEN** ответ содержит `Access-Control-Allow-Origin: *`

#### Scenario: Ограниченный список источников
- **WHEN** `CORS_ORIGINS=http://localhost:3000,https://example.com`, а клиент отправляет запрос с `Origin: http://localhost:3000`
- **THEN** запрос обрабатывается, и ответ разрешает этот источник

#### Scenario: Пустое значение
- **WHEN** `CORS_ORIGINS` задана пустой строкой
- **THEN** сервис разрешает все источники

#### Scenario: CORS для службы
- **WHEN** `FilePickerAPI.exe` работает службой, а в `.env` в папке exe указано `CORS_ORIGINS=https://example.com`
- **THEN** служба разрешает источник `https://example.com`
